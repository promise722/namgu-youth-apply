# 남구 청년 창업가 마케팅 지원 접수 PWA (프로토타입)

정책제안 「청년 창업가 마케팅 심화교육 및 마케팅비 지원 사업」의 온라인 접수 화면 시안입니다.
백엔드 없이 동작하며, 입력 데이터는 사용자의 기기(localStorage)에만 저장됩니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 셸 (헤더·내비·푸터), 시안 표시 마스트헤드 |
| `app.js` | 해시 라우터, 5단계 신청서(검증·임시저장·파일 첨부), 자격 자가진단, 내 접수, 관리(CSV/JSON) |
| `data.js` | 남구 17개 행정동, 업종 분류, 홍보 채널, 일정(1월 공고 → 2월 접수 → 3월 선발), 마감일, 서버 URL |
| `styles.css` | KRDS(대한민국 정부 디자인시스템) 토큰 적용. 출처: KRDS-uiux `tokens/figma_token.json` (Figma 라이브러리 내보내기) |
| `manifest.webmanifest` / `sw.js` / `icons/` | PWA 설치·오프라인 캐시 |

## 화면

1. **사업안내** — D-day, 핵심 수치(15명·200만 원·12회·자부담 10%), 8단계 일정, 자격·지원 내용, FAQ
2. **자격확인** — 5문항 자가진단 → 신청 가능/불가 안내
3. **신청하기** — ① 자격·인적사항 ② 사업체 정보 ③ 마케팅 현황 ④ 가점·서류 ⑤ 동의·제출(요약 확인). 입력 즉시 자동 임시저장, 단계별 검증, 제출 시 접수번호(NG27-####-XXX)와 접수증(인쇄/PDF)
4. **내 접수** — 이 기기의 접수 내역, 마감 전 수정
5. **관리** — 간이 PIN 잠금, 접수 목록·상태 변경(접수/서류검토/선발/예비/미선발), 행정동·업종 분포, CSV 내보내기, JSON 백업/가져오기

## 로컬 실행

```bash
python -m http.server 8765 --directory pwa
```

브라우저에서 `http://localhost:8765` 접속. PWA 설치·오프라인은 localhost 또는 HTTPS에서만 동작합니다.

## 배포 (정적 호스팅이면 어디든)

- Netlify / Vercel / GitHub Pages / 구청 웹서버의 하위 경로에 `pwa/` 폴더를 그대로 올리면 됩니다.
- HTTPS 필수(서비스워커). 하위 경로에 올릴 경우 `manifest.webmanifest`의 `start_url`·`scope`는 상대경로라 수정 불필요.

## 실제 운영 전환 시 해야 할 것

1. **접수 서버**: `data.js`의 `SUBMIT_ENDPOINT`에 접수 API URL을 넣으면 제출 시 JSON을 POST합니다. 서버가 없으면 Google Apps Script(시트 저장)나 구청 전자접수 시스템 연동을 권장.
2. **본인 확인**: 휴대전화 인증 또는 간편인증(정부24 방식) 추가.
3. **관리자 인증**: 간이 PIN을 담당자 계정(SSO)으로 교체.
4. **파일 첨부**: 현재는 700KB 이하만 기기에 저장(그 이상은 파일명만). 서버 연동 시 업로드 API로 교체.
5. **마스트헤드**: 정식 서비스로 전환 시 "시안" 표시를 제거하고 KRDS 공식 마스트헤드(정부 누리집 표시)로 교체.
6. **개인정보**: 개인정보 처리방침 링크, 보유기간(3년) 고지 문구를 법무 검토 후 확정.
